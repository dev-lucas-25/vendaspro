# 💼 VendaPro

## 📖 Sobre o Projeto

O **VendaPro** é um sistema de **Ponto de Venda (PDV)** desenvolvido como projeto acadêmico, com foco na gestão completa de processos comerciais. O sistema permite o gerenciamento de usuários, clientes, produtos, vendas, devoluções, recebimentos e relatórios gerenciais, oferecendo uma experiência prática de controle de operações comerciais.

O projeto foi desenvolvido utilizando tecnologias modernas para aplicações híbridas, proporcionando uma interface intuitiva, responsiva e adequada para dispositivos móveis.

## 🏗️ Arquitetura do Projeto

O sistema foi estruturado utilizando uma arquitetura baseada em:

* **Pages** → Interfaces do usuário
* **Services** → Regras de negócio e acesso aos dados
* **Models** → Estruturas de dados da aplicação
* **SQLite** → Persistência local dos dados
* **Angular Standalone Components** → Componentização moderna
