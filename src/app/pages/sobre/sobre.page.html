Sobre VendaPro

VendaPro

VendaPro é um aplicativo de ponto de venda (PDV) para demonstração acadêmica, focado em gerenciamento de clientes, produtos, vendas, devoluções e recebimentos.

Tecnologias utilizadas

  • Ionic Framework (Ionic Angular) — UI e componentes móveis
  • Angular — Estrutura de aplicação e rotas
  • TypeScript — Linguagem principal
  • sql.js (SQLite via WebAssembly) — Banco de dados SQLite em memória, persistido em LocalStorage
  • Capacitor — Integração nativa (configuração disponível)
  • Karma / Jasmine — Estrutura de testes (configuração presente)
  • SCSS — Estilização e tema
